# 传智杯 AI 大模型创新应用挑战赛 —— 演示视频分镜脚本与普通话讲解稿

> **时长控制**：约 **6 分 30 秒**（严格符合赛题 **5–8 分钟** 要求）  
> **录制规格**：OBS Studio 录制，`1920 × 1080 (1080p)`，`60fps` 或 `30fps`，输出格式 **MP4**，普通话配音 + 字幕（剪映自动识别字幕即可）

---

## 录制前准备（1 分钟检查）
1. 启动前后端服务（运行 `scripts\start_dev.bat`），浏览器全屏打开 `http://localhost:5173`，缩放比例设为 `100%`。
2. 准备好文件夹窗口 `scholar-agent\data\official_pdf\`，里面放好待现场拖拽上传的 `1706.03762v1.pdf` 与 `1706.03762v1_img.pdf`。

### 第二幕：模块一 · 语义去重、版本演进比对与多模态解析（0:50 – 2:15，约 85 秒）
- **【画面操作】**：
  1. 在「文献库与解析」页面，展示库内已有的 `1706.03762v7.pdf`、4 篇不同排版风格论文（IEEE/ACM/Springer/Nature）以及 **541 页**的《Understanding Deep Learning》教材。
  2. 将 `1706.03762v1.pdf` 拖入上传框 → 立即弹出「**语义级文献去重预警与版本比对**」窗口！展示文本指纹重合度、向量语义相似度、智能建议（「库中已有更新版本 v7，建议保留」）以及下方的「**Agent 自动总结两版本主要修订差异**」（指出英法 BLEU 从 41.0 更新为 41.8、新增版权声明等）→ 点击「保留库中现有版本」。
  3. 再将无文本层的扫描件 `1706.03762v1_img.pdf` 拖入上传（或点开已解析的扫描件/矢量论文的「结构化详情」抽屉），依次切换展示：**元数据与 1–3 级标题树**、**表格还原**、**LaTeX 公式渲染**、**图表裁剪**与**参考文献列表**；再点开 541 页教材展示其 181 节目录树。
- **【普通话讲解词】**：
  > 「首先是模块一：文献管理与多模态细粒度解析。目前知识库中已导入了 Attention Is All You Need 的最新 v7 版。现在我们上传较旧的 v1 版本。可以看到，系统并非依靠文件名，而是通过 **5-gram MinHash 指纹与 Embedding 语义相似度**，瞬间检测出正文高度重合，主动弹出预警，智能识别出库中 v7 比 v1 更新、建议保留现有版本，并自动对比总结出两版的核心修订差异——例如英法翻译 BLEU 分数由 41.0 修正为 41.8。  
  > 点开结构化详情，无论是双栏矢量 PDF、缺乏原生文本层的扫描件 `v1_img.pdf`，还是高达 **541 页**的深度学习教材，系统都能通过版面恢复、视觉多模态 OCR 与分批流式内存控制，精细抽取标题、作者机构、一至三级章节树、表格、LaTeX 公式、图表、参考文献及附录。」

### 第三幕：模块二 · 抗幻觉知识问答、源头溯源与多文联合推理（2:15 – 3:35，约 80 秒）
- **【画面操作】**：
  1. 切换到「抗幻觉 Agent 问答」模块。点击预设问题 1（询问作者机构、Adam 的 $\beta_1/\beta_2$、GPU 型号数量與 BLEU 分数）。
  2. **重点指向右侧「Agent 协同执行轨迹」面板**：展示实时流式推送的 `Memory 加载` → `Task Planner 多步规划` → `Function Calling 调用 search_papers` → `Critic 抗幻觉核查可信度评分`。
  3. 在生成的回答中，点击任意蓝色 `[E1 p.7]` 溯源锚点 → 画面自动跳转到阅读器第 7 页并用**黄色高亮框**精确定位原文段落！
  4. 切回问答页，点击预设问题 4（「对比 BERT 与原始 Transformer 在架构上的承袭与抛弃关系」）或输入「对比 GPT-1/2/3 参数量演化、LN 位置调整与 Context Window 递增过程」，展示生成的跨文献对比表格及各自对应的 `[E#]` 引用锚点。
- **【普通话讲解词】**：
  > 「接下来是模块二：抗幻觉知识问答与多文推理。当我们询问论文的作者机构、超参数 $\beta_1/\beta_2$、训练 GPU 型号数量以及 BLEU 分数时，右侧的 **Agent 协同执行轨迹面板** 实时展示了系统内部的白盒过程：先加载短期与长期记忆，由 Task Planner 拆解步骤，再通过 Function Calling 调用 **BM25 加稠密向量的混合检索**，最后由 **Critic Agent** 逐句核对数值与事实一致性。  
  > 回答精准给出了 $\beta_1=0.9, \beta_2=0.98$、8 张 NVIDIA P100 GPU 以及 28.4 和 41.8 的 BLEU 分数。每个结论都附带可点击的原文锚点，点击即可直达 PDF 对应页码并高亮原文位置。对于跨文献联合推理，如对比 BERT 与 Transformer 的承袭与抛弃、GPT-1 到 GPT-3 的参数量、Pre-LN 与 Post-LN 位置演化，Planner 会实施多文均衡检索并输出结构化对比表格；若遇到文献未提及的虚假概念，Guardrails 会严格触发拒答，彻底杜绝幻觉。」

### 第四幕：模块三 · 版式感知阅读、双向引用跳转与中英同步滚动（3:35 – 4:25，约 50 秒）
- **【画面操作】**：
  1. 在「阅读与双向翻译」页面，点击左侧 1–3 级标题树任意小节跳转页面。
  2. 在PDF或右侧原文中用鼠标划选一段英文 → 点击顶部「划词翻译」气泡查看精准译文与专业术语对照。
  3. 拖动右侧「中英对比联动滚动」区域的滚动条，展示左原文、右译文**自动同步滚动**，且数学公式完整保留 LaTeX 渲染。
  4. 点击正文中的蓝色引用标记 `[11]` → 自动跳到右侧「双向引用跳转」面板并定位到第 11 条参考文献（He et al. ResNet）；再点击该条目下的绿色标签「↑ 跳回正文引用处 p.6」→ 立即反向跳回正文第 6 页！
- **【普通话讲解词】**：
  > 「模块三是版式感知阅读与双向联动翻译。左侧提供一至三级标题树导航，中间基于 PDF.js 原生高保真渲染双栏、公式与表格。鼠标划词即可呼出含专业术语表的即时学术翻译；开启整篇翻译后，右侧双栏支持**中英对照自动同步滚动**，且所有代码与数学公式严格保留英文原貌，支持一键导出 Markdown 或 HTML。  
  > 同时，正文中所有引用标记如 `[11]` 均与文末 References 建立了双向锚点：点击正文 `[11]` 可直达文末参考文献条目，点击参考文献上的『跳回正文引用处』又能无损返回正文对应位置。」
